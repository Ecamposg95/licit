# Paquete maestro Dipromedic

1. Leer Dossier_Dipromedic_Fase_1.docx para el alcance de negocio.
2. Entregar Task_Pack_Maestro_Dipromedic.md al responsable técnico o a la IA de desarrollo.
3. Usar datos_demo.json como fixtures iniciales y catalogo_ficticio.csv para probar importación.

El JSON contiene 18 variantes ficticias, 8 escenarios, 3 referencias históricas reales, 20 requisitos sintéticos, metadatos de 12 documentos y 10 tareas. Los metadatos no son los archivos de esos documentos: el equipo deberá producir los documentos de prueba con la marca indicada. Ningún producto, precio o capacidad representa una oferta real.

Este paquete es una especificación para comenzar el desarrollo. No incluye una aplicación ya construida, credenciales ni conectores implementados. Los importes de la propuesta están pendientes de definir. El dossier está preparado en modalidad white label; el task pack es interno y sí identifica al equipo ejecutor.
